# Fable Crown game releases

This repository contains the public playable game and the configuration that publishes it on GitHub Pages. Game source, authoring assets, prototypes, and internal work are maintained separately.

[Play the live game](https://cudldev.github.io/Fable-Crown-Game/) · [Play the Whispers development preview](https://cudldev.github.io/Fable-Crown-Game/whispers-preview/?demo=developed)

In Whispers, open **Wardrobe** to try an outfit. The **Time** menu lets you hold the light at a chosen hour or resume the 20-minute day. [Try an accelerated sunset](https://cudldev.github.io/Fable-Crown-Game/whispers-preview/?demo=developed&hour=17&dayCycle=24).

Whispers starts with **Tile → None** at 360p. Choose **2×2** in the Tile menu for a 720p tiled view. The mobile performance preview uses 180p with None and 360p with tiles, plus smaller shadows and GPU timings. [Open the mobile performance preview](https://cudldev.github.io/Fable-Crown-Game/whispers-preview/?demo=developed&mobile=1&gpuPasses=1).
